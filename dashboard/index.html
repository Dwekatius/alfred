Set up your assistant

Follow the steps in order. Green checks update automatically — everything runs on this PC, and secrets are encrypted with Windows DPAPI (never sent anywhere except the services you configure).

01

Install the prerequisites

You need these on the PC. If you launched Setup Alfred.cmd, Node and the Python environment were installed automatically — this checklist just confirms it.

    Downloads: Node.js 24 LTS · Python 3.14 · Google Chrome. If you install Python, tick “Add python.exe to PATH” in the installer.

    02

    Create your own Telegram bot

    1. Open Telegram and search for @BotFather (the verified account with a blue check).
    2. Send /newbot. Choose a display name (anything) and a username that ends in “bot”, e.g. mohans_pc_agent_bot.
    3. BotFather replies with a token that looks like 123456789:AAH.... Copy the whole line.
    4. Paste it below and press Verify & save. It is checked with Telegram, then encrypted on disk.
    This bot has a webhook configured, which blocks polling.
    03

    Pair your Telegram chat

    Only your account may talk to the bot. We verify it with a one-time code that exists only on this PC.

    1. Open the chat with your bot: open in Telegram (or search for @yourbot).

    2. Press START, or send this exact command:

    /start ...

    3. Come back here and accept your account as the owner.

    Waiting for your /start message…
    04

    Choose the AI model

    Any number of model slots are supported. The slot marked ACTIVE handles the next job; switch in Telegram with /model <slot>. Keys are validated against the provider and stored with Windows DPAPI. Local OpenAI-compatible servers (LM Studio, Ollama, vLLM) need no cloud key.

    Add a provider
    05

    Sign in to your accounts (browser)

    The agent uses its own Chrome profile so your normal browsing stays private and untouched. Sign in once to Gmail or any other site you want it to use, then close that Chrome window.

    06

    Start using it

    Start the assistant, then message your bot from Telegram.

    Try these in the chat:

    Summarize the latest 10 emails in my inbox and list anything urgent.
Open Notepad, write a short report about today, save it on my Desktop, and send a screenshot.
/screenshot      /status      /pause      /resume      /stop
/model deepseek  /model openrouter <model-id>  /provider auto  /thinking max

    Stopping: Ctrl+Alt+F9 on the PC is the emergency stop. The tray icon (bottom-right) can pause, resume, and stop the agent any time.

    Troubleshooting

    The bot does not reply
    • Check the status dot at the top — if the assistant is stopped, press Start assistant.
    • Make sure you paired the right Telegram account (step 3) and that you message the bot's private chat.
    • On the PC: the tray icon turns gray when the agent is stopped; red/orange means a problem — open the logs.
    • If you restarted the PC, sign in to Windows — the agent starts automatically at sign-in.
    It replies but cannot click or type
    • The PC must be unlocked. A locked screen pauses desktop actions on purpose.
    • Windows blocks automation of elevated (admin) windows. If an app runs as administrator, tell the agent and it will explain the limitation.
    • If it says the observation is stale, just try again — it re-takes a screenshot.
    Clicks land in the wrong place
    • Don't change the display scaling or move windows while it is working.
    • Ask it to take a fresh screenshot before each step; it is designed to do that automatically.
    Chrome lost the site login
    • Open the sign-in button above and log in again in the agent's dedicated profile.
    • Websites still expire sessions or ask for CAPTCHA/MFA. Complete it in the visible window and tell the agent to continue.
    The free OpenRouter model stopped working
    • Free models are rate-limited and occasionally unavailable. Switch to DeepSeek with /model deepseek.
    Where are the logs and data?
    • Everything lives under your user profile: %USERPROFILE%\.pi\alfred
    • logs - structured diagnostics (no secrets), artifacts - screenshots, sessions - chat transcripts.
    • Backups: powershell -File scripts\backup.ps1
